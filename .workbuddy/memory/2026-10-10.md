## 满屏设计 + 修复按钮全部失效的关键 bug
- **关键 bug**：formatter 页 `<script>` 的 import 路径写成 `../lib/json/format`，而页面位于 `src/pages/json/`，正确为 `../../lib/json/format`。模块解析失败导致整个脚本不加载 → 所有功能按钮无响应。⚠️ 以后 Astro 页面内 script 的相对 import 必须从页面文件所在目录算起。
- **满屏模式**：Base.astro 新增 `full` prop —— body `h-full overflow-hidden`（锁定视口）、main 改为 `flex flex-col overflow-y-auto lg:overflow-hidden` 且放开 max-w 限制；首页等普通页面不受影响（默认 false）。
- formatter 页改为满屏双栏：页头单行紧凑（标题+面包屑同行），编辑区 flex 撑满剩余视口高度（移动端 `h-72` 固定高防 flex-basis:0 塌陷，`lg:h-auto lg:flex-1` 撑满）；状态栏压缩为单行 h-5。
- **失焦自动格式化**：input blur → 合法则输出框自动显示格式化结果，空则跳过，非法则报错并定位行列；缩进下拉 change 即时重排；Ctrl/Cmd+Enter 快捷格式化；「示例」载入后直接格式化；复制/下载增加空输出防护；清空后自动聚焦输入框。

## 编辑框固定高度 + 右栏默认树视图（本轮微调）
- 编辑框改为**固定沾满高度、不动态加高**：grid 加 `lg:grid-rows-[minmax(0,1fr)]` 锁定行高，textarea/tree 用 `flex-1 min-h-0`（内容滚动不撑高），移动端 `min-h-[18rem]` 兜底；去掉原先 `h-72 lg:h-auto` 的高度不稳定写法。
- **右栏默认树视图**：`treeVisible` 初值 `true`、output 默认 `hidden`；格式化/压缩/排序键/转义/反转义/示例/失焦全部走 `setResult()`（写 output.value 供复制下载 + 渲染树）；新增 `renderTreeFromInput()`（空态提示、非法报错定位）。
- 新增「展开全部 / 折叠全部」按钮（`data-act=expand/collapse`），节点加 `.tree-toggle`/`.tree-children` class 批量控制；「树视图」按钮改为 树视图↔原文 切换。

## 框架全宽 + 修复 full 模式实际未生效的隐患
- 用户要求整体框架（顶栏/内容/页脚）**沾满浏览器宽度**：Header 容器去掉 `mx-auto max-w-7xl`（改 `flex w-full ... px-4`）；Base main 去掉 `mx-auto max-w-7xl`（改 `w-full`）。Footer 本来即全宽。
- **关键隐患**：上一轮对 Base body 的 `full` 模式 class:list 改造实际未落盘，文件一直是旧版 `<body class="flex min-h-full...">`，导致 `full` prop 长期空操作、满屏高度从未真正锁定。现已重写：body 用 class:list（full→`h-full overflow-hidden`，否则`min-h-full`），main 用 class:list（full→`flex flex-col overflow-y-auto lg:overflow-hidden`）。formatter 页 `full` 属性至此才真正生效。

## 修复：左侧「编辑」按钮看似「没实现」的 bug
- 现象：左侧 格式化/压缩/排序键/转义/反转义 点击后无可见变化。根因：`setResult()` 把结果写进了**默认 hidden 的 #output**，且 `renderTreeFromInput()` 解析的是**未变的 input**，默认树视图下结构不变 → 看起来像没反应。
- 修复：新增 `applyToInput()`，左侧 格式化/压缩/排序键 改为**原位编辑 input.value**，右侧树视图与 output 实时跟随；失焦自动格式化、缩进切换也改为写回 input。转义/反转义仍写 output 并切到「原文」视图（其结果是字符串字面量，不适合当作 JSON 源）。复制/下载改为从当前 input 实时格式化（不再依赖可能过期的 output）。
